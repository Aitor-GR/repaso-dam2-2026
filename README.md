# Repaso de GIT para alumnos de DAM2 - Curso 2026/27

* Hazte un fork del repositorio: www.github.com/cristinagom/repaso-dam2-2026
* Trabaja con el modelo de ramas propuesto en GitFlow y crea la rama dev
* Crea una Feature con Apellido1Apellido2Iniciales, por ejemplo (GomezAlonsoC)
* En esa Feature crea un txt llamado Apellido1Apellido2Iniciales.txt (GomezAlonsoC.txt)
* Rellena ese fichero con tus apellidos y nombre completos : el usuario de GitHub. En mi caso: "Gómez Alonso, Cristina : cristinagom"
* Cambia el fichero listado.txt con y añade también tus apellidos y nombre en la última linea disponible, tu rol (alumno DAM1, DAW1...) y tu Github username.
* Cierra la Feature siguiendo el flujo de GitFlow
* Confirma los cambios y mergea a tu dev
* Hazme un pull request para que acepte los cambios y explícame dichos cambios en tu pull. Debes hacérmelo a rama main desde tu rama dev. Si no se explican correctamente los cambios y lo que has hecho en el Pull Request será denegado y rechazado.
* Aplica las acciones oportunas para tener todo sincronizado y volver a tener los cambios una vez sincronizado.
